# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be kind and respectful, welcome different viewpoints, accept constructive criticism, and
tolerate neither harassment nor discriminatory remarks.

Unacceptable behavior can be reported privately with GitHub's **Report content** option, available in
the "…" menu of every issue, pull request and comment. Reports reach the maintainers and GitHub, and are
handled confidentially.
